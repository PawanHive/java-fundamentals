# 📘 OOP in Java — Destructors

---

## 🔷 What is a Destructor? (General Concept)

A **destructor** is a special method used to:

> Destroy an object and free memory when it is no longer needed.

👉 This concept exists in languages like **C++**

---

## 🔴 Does Java Have Destructors?

❌ **No, Java does NOT have destructors**

---

## 🔷 Why No Destructors in Java?

Java uses:

👉 **Garbage Collection (GC)**

- Automatically detects unused objects  
- Frees memory automatically  
- No need for manual deletion  


# 🧠 Interview Line

Java does not support destructors; instead, it uses garbage collection to automatically manage memory and destroy unused objects.

# 🔥 Final Insight

👉 In Java:
**You don’t delete objects — JVM does it for you**
