# 📘 OOP in Java — Single Level Inheritance

---

## 🔷 What is Single Level Inheritance?

Single Level Inheritance means:

> **One child class inherits from one parent class**

👉 Simple meaning:  
**Only one level of inheritance (direct relationship)**

---

## 🔷 Structure

~~~text
Parent Class → Child Class
~~~

---

## 🔷 Syntax

~~~java
class Parent {
  // properties & methods
}

class Child extends Parent {
  // inherits from Parent
}
~~~
