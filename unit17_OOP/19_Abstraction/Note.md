# 📘 OOP in Java — Abstraction

---

## 🔷 What is Abstraction?

Abstraction means:

> **Hiding implementation details and showing only essential features to the user**

👉 Simple meaning:  
You focus on **what something does**, not **how it does it**

---

## 🔷 Real-Life Analogy 🧠

- You use a **mobile phone 📱**
  - You can call, message, use apps
  - But you don’t see internal circuit logic

👉 You only use features, not internal complexity  
→ This is abstraction

---

## 🔷 Why Abstraction is Used?

✔ Hides complexity  
✔ Improves security  
✔ Reduces code complexity  
✔ Makes code easier to use and maintain  

---

# 🔷 Ways to Achieve Abstraction in Java

1. Abstract Classes  
2. Interfaces  


# 🧠 Interview Line

Abstraction is the process of hiding implementation details and showing only essential features to the user using abstract classes and interfaces.

# 🔥 Final Insight

👉 Abstraction = **focus on what, hide how**
