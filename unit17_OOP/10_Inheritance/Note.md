
# 📘 OOP in Java — Inheritance

## 🔷 What is Inheritance?

Inheritance is a mechanism where:

Inheritance is when properties & methods of **base(parent) class** are passed on to a **derived(child) class.**

👉 Simple meaning:  
**“Reuse code from another class”**

---

## 🔷 Why Use Inheritance?

✔ Code reusability  
✔ Avoid code duplication  
✔ Better structure and organization  
✔ Easier maintenance  

---

## 🔷 Basic Syntax

~~~java
class Parent {
  // properties & methods
}

class Child extends Parent {
  // inherits from Parent
}
~~~

## 🔷 Key Concept

👉 `extends` keyword is used to inherit a class

---

## 🔷 What Gets Inherited?

✔ Variables (properties)  
✔ Methods (functions)  

---

## 🔴 What Does NOT Get Inherited?

❌ Constructors  
❌ Private members (directly)  

---

## 🔷 Types of Inheritance in Java

1. Single Level Inheritance  
2. Multilevel Inheritance  
3. Hierarchical Inheritance  
4. Hybrid Inheritance (not fully supported using classes)

## 🧠 Interview Line

Inheritance is a mechanism in Java where one class acquires the properties and behaviors of another class using the `extends` keyword.
